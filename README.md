🚀 Projeto Python — Programa Jovem Tech
📌 Sobre o projeto

Este projeto foi desenvolvido como parte do Programa Jovem Tech, com o objetivo de colocar em prática os conhecimentos adquiridos durante os estudos de programação em Python.

A aplicação busca desenvolver o raciocínio lógico, a resolução de problemas e a construção de soluções utilizando conceitos fundamentais da linguagem Python.

🎯 Objetivos
Praticar os fundamentos da programação em Python.
Desenvolver o raciocínio lógico e computacional.
Aplicar conceitos de variáveis, estruturas condicionais, laços de repetição e funções.
Estimular a criatividade e a resolução de problemas por meio da tecnologia.
🛠️ Tecnologias utilizadas
Python 3 — linguagem de programação utilizada no projeto.
Git — controle de versão.
GitHub — hospedagem e compartilhamento do código-fonte.

📚 Aprendizados

Durante o desenvolvimento, são trabalhadas habilidades como:

Lógica de programação.
Organização e legibilidade do código.
Identificação e correção de erros.
Resolução de problemas.
Utilização do Git e do GitHub para versionamento.
